# PROGNODE V0.7.1 DEV2 UI / Brand Spec

## Locked brand direction
- Identity: B1
- Primary background: Deep Navy `#0A1B2E`
- Primary accent: Cyan `#00D9FF`
- Secondary accent: Teal `#00B3A6`
- Light text: Light Slate `#E6EDF4`
- Product descriptor: `Industrial Monitoring`
- Tagline direction: `Monitor today. A more reliable tomorrow.`

## Overview rule — locked
Overview artık onboarding sayfası değildir. **Quick Start / commissioning path Overview içinde gösterilmez.**

Sistem boşken de aynı operational dashboard iskeleti görünür ve değerler `0` / empty-state olarak başlar. Device, Tag, Alarm, Historian ve Notification verileri geldikçe aynı kartlar gerçek runtime verisiyle dolar.

## Operational dashboard
- Branded industrial hero
- Total Devices / Live Tags / Active Alarms / Recording Tags / Historian Points / Core Health KPIs
- Device Health ring based on communication-loss alarms and Tag quality
- Active alarms feed
- Recent notifications feed
- Historian / recording status with DB size, recording count and quality
- Quick actions: Add Device / Add Tag / Create Alarm / Add to Historian / Create Trend / Import CSV
- Sidebar industrial visual + B1 brand statement

## Navigation
Primary navigation: Overview, Devices, Tags, Alarms, Trends, Historian, Import / Export, Notifications, Settings. Diagnostics and License are not shown in the primary sidebar.

## Product rules
- No `Add your first device` CTA in Overview.
- No Quick Start card in Overview.
- No fake uptime percentage until Core exposes a real uptime metric.
- No fake historian-today count until backend exposes time-window stats.
- UI values must come from runtime state / persisted storage.
