# PROGNODE V0.7.2 DEV13.0 — Core WOW / Global Product UI

This release is a UI/UX productization pass only. Existing backend API contracts, licensing, routing and runtime behavior are preserved.

Key changes:
- Unified Core design tokens with PROGNODE web brand palette.
- Navigation split into Operations / System information architecture.
- Consistent page headers, panels, KPI cards, utility actions, tables, forms and modals.
- Semantic device status badges (good / warning / bad / neutral).
- Compact import/export utilities to reduce visual noise.
- First-class light theme instead of simple dark-theme inversion.
- More readable dense tables for long-running industrial use.
- Standard primary / secondary / danger interaction hierarchy.
- Refined Overview brand strip with local-first product message.
- Maintains desktop-first responsive behavior.

Brand message used in Core:
- See sooner. Act faster. Run longer.
- Process data stays on-site.
