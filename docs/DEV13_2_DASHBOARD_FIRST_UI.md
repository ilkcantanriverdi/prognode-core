# PROGNODE DEV13.2 — Dashboard-first UI

Release decision:
- No industrial/factory photography inside the operational Overview dashboard.
- No promotional slogan card in the sidebar.
- Overview starts directly with live KPI cards, device health, alarms, notifications, historian status and quick actions.
- Marketing/brand storytelling belongs to the public website; Core prioritizes operational information density.
- Sidebar contains brand identity, product navigation and Core status only.
- Light and dark modes use the same information architecture and differ only in purpose-built surface tokens.

Web handoff:
- Keep the public website free to use richer brand storytelling.
- For product/app screenshots and authenticated areas, use the dashboard-first principle: data before decoration.
