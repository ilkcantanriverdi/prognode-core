# PROGNODE V0.7.2 — Server / Client Architecture

## Decision

Configuration and process data stay on the customer site. the **PROGNODE Account Cloud** stores only identity, organization, license/activation and installation metadata. It does **not** store Devices, Tags, Alarm Definitions, Historian samples or Trend data.

## Products

### PROGNODE Server
- Licensed component.
- Windows Service / Linux daemon.
- Owns PLC/protocol connections, Tag Runtime, Alarm Engine, Historian and configuration database.
- One engineering configuration is made here.
- Exposes the authenticated PROGNODE API/Web UI on LAN.

### PROGNODE Client for Windows
- Free operator/engineering client.
- Does not poll PLCs and does not create a second Historian.
- Connects to a selected PROGNODE Server over LAN/VPN.
- Uses server-side users/roles and the Server license.
- Multiple clients can view the same Server without duplicating configuration.

### PROGNODE Mobile
- Android/iOS client of the same Server.
- Active alarms, notifications and ACK actions are sent back to the Server.
- Process configuration/data does not need to be mirrored to the public account portal.

## Second PC scenarios

1. **Second operator/engineering PC:** install the free Client, enter/discover the Server, sign in. No reconfiguration.
2. **Server replacement:** export a local PROGNODE configuration backup and restore it on the replacement Server.
3. **Future HA:** Primary/Standby Server is a separate feature. A Client is never treated as a second Server.

## Portal responsibility

the **PROGNODE Account Cloud**:
- user/organization management
- licenses and activation keys
- installation/server registry
- setup downloads
- license status / revocation / renewals

No process configuration cloud sync is required.

## Configuration backup direction

A future `.pgnbackup` package should contain configuration DB data (Devices, Tags, Alarm Definitions, Historian configuration, Trends, settings) with an option to include or exclude historical process data. Default: configuration only.
