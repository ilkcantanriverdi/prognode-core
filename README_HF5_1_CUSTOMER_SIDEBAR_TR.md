# HF5.1 müşteri arayüzü — sol menü düzeltmesi

Bu paket HF5 tam kaynak paketinin üstüne yalnızca görsel düzenleme uygular. Şişkin VIEW ONLY bannerı, gereksiz ikinci sayfa başlığı, tam sürüm kartı ve ayrı saat/tarih kutusu sadeleştirildi. Lisans ve oturum yönetimi kaldırılmadı: aynı elemanların kimlikleri ve API çağrıları korunuyor. Sistem durumu, saat, tema/dil ve oturum alt kısımda kompakt.

**Önemli:** Görsel düzenleme kaynak düzeyinde uygulandı; bu ortamda Chromium önizlemesi zaman aşımına uğradı. Gerçek Core, kimlik doğrulama, Trend Studio performansı ve Windows .NET kabul testleri yapılmadı. Önceki çalışan sistemin data klasörünü ve HTTPS sertifikasını silmeyin. Bu bir müşteri final/release sertifikası değildir.

Kurulum: temiz klasöre açın, HF5 için kullandığınız başlatıcıyla derleyin ve güncel sayfayı Ctrl+F5 ile açın. Yanlışlıkla eski HF5 arayüzünü görürseniz önbelleği temizleyin.
